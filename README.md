# tiny-french-llm

A tiny, open, French-only tutor LLM — trained from scratch (own tokenizer, own weights) on free GPU infrastructure, running fully offline on a MacBook Air via Ollama or MLX.

## Purpose

Give a French learner at an intermediate level (A2-B1) an always-available, private, offline French tutor: grammar and vocabulary explanations, corrections of learner mistakes with French explanations, and short sample dialogues — all in French, never English.

The project is also an educational artifact: the repository documents the complete, reproducible training process (decisions, estimates, failure modes), so anyone can learn to train an LLM from scratch on free infrastructure.
